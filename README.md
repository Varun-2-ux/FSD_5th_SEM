## 🎬 Final Project: CineScope PRO
- **Location**: [Final_Project/CineScope](./Final_Project/CineScope)
- **Tech Stack**: React 18, Vite 5, React Router v6, Lucide Icons, CSS Custom Properties
- **Catalog**: 92 curated motion pictures across Global Blockbusters, Bollywood & Indian Cinema, and Anime Masterpieces.
- **Features**: Real-time debounced & instant search, multi-criteria filters, YouTube trailer modal, responsive carousels, persistent watchlist/favourites, dark/light theme toggle.
